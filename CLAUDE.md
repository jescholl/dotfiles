# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

Personal dotfiles based on [holman/dotfiles](https://github.com/holman/dotfiles), organized by topic. There is no build step or test suite — changes take effect when shell sessions reload or when `bootstrap/bootstrap` is re-run.

## Bootstrap / install

```sh
bootstrap/bootstrap
```

This runs all `preinstall.sh` scripts, symlinks `*.symlink` files, clones `*.git_list` repos, runs all `install.sh` scripts, then `postinstall.sh` scripts. It's idempotent and interactive (prompts on conflicts).

To reload the shell after editing zsh files:
```sh
reload!   # alias defined in zsh/aliases.zsh
```

## Topic structure

Each subdirectory is a topic. The framework auto-loads files by naming convention — **no registration needed**:

| Filename pattern | When loaded | Purpose |
|---|---|---|
| `topic/path.zsh` | First | Set `$PATH` or similar |
| `topic/*.zsh` | Middle | Aliases, functions, config |
| `topic/completion.zsh` | Last (after `compinit`) | Shell completions |
| `topic/*.symlink` | `bootstrap/bootstrap` | Symlinked to `~/.filename` (extension stripped) |
| `topic/*.git_list` | `bootstrap/bootstrap` | Repos to clone into `.__dotfiles_scratch__/topic/name/` |
| `topic/preinstall.sh` | Before linking | Setup that must run first |
| `topic/install.sh` | After linking | Tool installation |
| `topic/postinstall.sh` | After install | Finalization |

## Key paths

- `DOTFILES_ROOT` — this repo's root (`/Users/jscholl/home/dotfiles`)
- `DOTFILES_SCRATCH` — generated/runtime files (`.__dotfiles_scratch__/`), not meant to be edited directly
- `bin/` — scripts added to `$PATH` automatically
- Local overrides go in `~/.env.local.sh`, `~/.env.local_zsh.sh`, `~/.env.local_mac.sh` (not in this repo)

## Generated files in `.__dotfiles_scratch__/`

These are created by bootstrap scripts and should not be hand-edited:

- `env.dotfiles.sh.symlink` — exports `DOTFILES_ROOT` and `DOTFILES_SCRATCH`; generated by `system/preinstall.sh`
- `gitconfig.dynamic.symlink` — contains git `[user]` identity; generated by `git/preinstall.sh` from `git/gitconfig.dynamic.symlink.template`
- `vim/bundle/` and `zsh/plugins/` — cloned plugin repos

## Vim plugin management

Plugins are managed via [Pathogen](https://github.com/tpope/vim-pathogen). The plugin list is in `vim/bundle.git_list`. Pathogen loads bundles from `DOTFILES_SCRATCH/vim/bundle/`.

## Notable conventions

- `tf` / `tg` (in `system/aliases.zsh`) detects `terragrunt.hcl` and transparently calls `terragrunt` or `terraform`
- `kubectl` (in `system/grc.zsh`) is wrapped to skip `grc` coloring for interactive subcommands (`exec`, `attach`, `debug`, `run`) to avoid broken newlines
- `aws_assume_role <arn>` (in `zsh/aliases.zsh`) exports AWS credential env vars for the current shell
- `zsh/prompt.zsh` uses a two-line prompt with git branch info from `gitprompt`
